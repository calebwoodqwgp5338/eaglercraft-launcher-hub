## Overview

Eaglercraft Launcher provides a web interface for starting the Eaglercraft versions bundled with the project. It combines an original client, two modified client variants, and JavaScript-based builds in a single launcher.

Because it is browser-based, the launcher provides access to the included clients without depending on a conventional desktop launcher. The project is actively updated, so the set of available versions and the contents of the launcher can change over time.

## Troubleshooting Guide

### The web page will not load

Check the download address and refresh the page. For a local installation, make sure the repository was cloned or downloaded without missing files.

### A selected client fails to start

Go back to the launcher and choose the client again. You can also test another included Eaglercraft version to see whether the problem affects only one client option.

### JavaScript is not available

Verify that JavaScript is enabled in the browser, then reload the launcher. When using a local copy, run the files through a local web server if opening the HTML file directly does not provide the browser behavior the launcher requires.

### Some local files are missing

Clone or download the repository again. Confirm that the expected HTML and JavaScript files exist in the project directory.

### The interface changed after updating

Active development may alter the available versions, client entries, or launcher behavior. Check the contents of the current published build before opening an issue.
